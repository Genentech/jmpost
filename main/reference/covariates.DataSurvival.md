# Extract Covariate Names for Survival Data

Extract Covariate Names for Survival Data

## Usage

``` r
# S3 method for class 'DataSurvival'
covariates(object, ...)
```

## Arguments

- object:

  (`DataSurvival`) Survival data object to extract covariate names from.

- ...:

  not used.

## Value

A character vector containing the covariate names.
