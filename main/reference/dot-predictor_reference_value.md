# Obtain a predictor's reference-level initial value

Obtain a predictor's reference-level initial value

## Usage

``` r
.predictor_reference_value(prior, parametrization)
```

## Arguments

- prior:

  A
  [`Prior`](https://genentech.github.io/jmpost/reference/Prior-class.md)
  object for the predictor intercept.

- parametrization:

  Character scalar naming the predictor parametrization.

## Value

The median reference-level parameter value on its natural scale.
