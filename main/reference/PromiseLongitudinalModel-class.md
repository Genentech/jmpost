# Promise of a `LongitudinalModel`

An object that promises to resolve to a
[`LongitudinalModel`](https://genentech.github.io/jmpost/reference/LongitudinalModel-class.md)
object.

## Usage

``` r
PromiseLongitudinalModel()
```

## Value

A `PromiseLongitudinalModel` object.

## Examples

``` r
PromiseLongitudinalModel()
#> An object of class "PromiseLongitudinalModel"
#> <S4 Type Object>
```
