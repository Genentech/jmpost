# Coerce to `CmdStanMCMC`

Coerces an object to a
[`cmdstanr::CmdStanMCMC`](https://rdrr.io/pkg/cmdstanr/man/CmdStanMCMC.html)
object

## Usage

``` r
as.CmdStanMCMC.JointModelSamples(object, ...)
```

## Arguments

- object:

  to be converted

- ...:

  additional options

## Value

The underlying
[`cmdstanr::CmdStanMCMC`](https://rdrr.io/pkg/cmdstanr/man/CmdStanMCMC.html)
object.
