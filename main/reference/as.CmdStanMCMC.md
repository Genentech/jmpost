# Coerce to `CmdStanMCMC`

Coerces an object to a
[`cmdstanr::CmdStanMCMC`](https://mc-stan.org/cmdstanr/reference/CmdStanMCMC.html)
object

## Usage

``` r
as.CmdStanMCMC.JointModelSamples(object, ...)
```

## Arguments

- object:

  to be converted

- ...:

  additional options

## Value

The underlying
[`cmdstanr::CmdStanMCMC`](https://mc-stan.org/cmdstanr/reference/CmdStanMCMC.html)
object.
